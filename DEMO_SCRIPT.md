# ASTROCARE — 30-second demo script

“Meet ASTROCARE, a mission-focused health monitoring prototype for long-duration spaceflight. The overview brings key health indicators and trends into one place. These readings are clearly labelled synthetic demo data, not real astronaut telemetry. I can add a health record, compare it with a personal baseline and generate an explainable alert using configurable rules. The app also tracks exercise, sleep, mental wellness and manually entered radiation exposure. It stores records locally, exports a health summary and demonstrates a delayed-communications queue. Finally, the References page connects the feature design to NASA human research and public OSDR studies, while clearly distinguishing research datasets from live vital signs.”


**NASA data moment (10 seconds):** Open NASA Research Data, select OSD-569, change the blood parameter and participant code, and show the seven collection timepoints. Explain that these are actual processed CBC laboratory results from Inspiration4 ground collections, not continuous vital signs. Then switch back to Mission Overview and point out the synthetic-data banner.
